# Contributing

Boxy is not yet open to outside code contributions. The architecture and
conventions are still actively settling — see `AGENTS.md`'s living
"Architectural Notes" and "Lessons Learned" sections for a sense of how much
is still in motion — and reviewing external PRs against a moving target
isn't a good use of anyone's time right now. That will change once the
architecture stabilizes (roughly: after v1), but there's no firm date yet.

**Issues and questions are welcome.** Bug reports, design questions, and
feature ideas via [GitHub issues](https://github.com/Geogboe/boxy/issues)
help shape the project even while it isn't accepting PRs — please just don't
expect a PR to go with one to be reviewed or merged yet.

If you've opened a PR before reading this: sorry for the wasted effort —
please open an issue instead, and check back once this notice is gone.
